How Cypress Copilot Works

Four simple steps from Gherkin feature file to executable Cypress test.

01

Input Scenario

Paste your Gherkin BDD scenario into the extension panel in VS Code.

02

Select LLM Model

Choose your preferred OpenAI model (e.g. GPT-4o) using your secure API key.

03

Chain Prompting

The extension applies specialized few-shot chain prompts behind the scenes.

04

Generate & Review

Instantly receive clean step definition files and Page Object Model classes.

Get Started in Seconds

1

Install via VS Code Extensions Marketplace

Search for Cypress Copilot inside Visual Studio Code and click Install.

2

Activate Command Palette

Press Ctrl+Shift+P or Cmd+Shift+P and run Cypress Copilot.

3

Add OpenAI API Key

Input your OpenAI API key in the configuration panel to enable generation.
